# Modifier lenses

A modifier changes the actions a laser already carries when it meets it: those in slots to its left in the mount, and those from mounts before. It never changes one that comes after.

## Reach

| Lens | What it does |
| --- | --- |
| [[item:range_lens]] | Doubles how far each run reaches. |
| [[item:phantom_lens]] | The laser passes through blocks. Costs power per block, and doubles action costs. |

## Targeting

| Lens | What it does |
| --- | --- |
| [[item:filter_lens]] | Limits item actions to listed items. |
| [[item:block_filter_lens]] | Limits Harvest to listed blocks. |
| [[item:entity_filter_lens]] | Limits Damage, Healing, Freezing and Interact to listed entities. |

## Output

| Lens | What it does |
| --- | --- |
| [[item:pickup_lens]] | Returns freed items up the laser to a Laser Port. |
| [[item:void_lens]] | Destroys freed items nothing takes. |
| [[item:smelting_lens]] | Smelts items on the way. |
| [[item:crushing_lens]] | Crushes items on the way. |
| [[item:unrealising_lens]] | Ore comes away as Unrealized Matter. |

## Power and speed

| Lens | What it does |
| --- | --- |
| [[item:amplify_lens]] | Harder cuts, harder hits and heals. |
| [[item:speed_lens]] | Actions work twice as fast per lens. |

## Harvest quality

| Lens | What it does |
| --- | --- |
| [[item:precision_lens]] | Silk Touch. |
| [[item:harmonic_lens]] | Fortune and Looting. |

## Control

| Lens | What it does |
| --- | --- |
| [[item:isolator_lens]] | Lets power through, and only what else it is set to pass. |
| [[item:uv_lens]] | Hides the laser. |
