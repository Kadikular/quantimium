# Action lenses

An action lens gives a laser something to do. A laser can carry several actions, and an action stays on the laser until it ends.

| Lens | What it does |
| --- | --- |
| [[item:harvest_lens]] | Breaks the block the laser ends on. |
| [[item:damage_lens]] | Hurts what stands in the laser. |
| [[item:healing_lens]] | Heals what is living in the laser, and hurts the undead. |
| [[item:freezing_lens]] | Freezes machines, mobs, players and water. |
| [[item:interact_lens]] | Uses an item or an empty hand on what the laser ends on. |
| [[item:acceleration_lens]] | Speeds up the machine the laser ends on. |
| [[item:place_lens]] | Places blocks a Laser Port sends. |
| [[item:insert_lens]] | Puts items from a Laser Port into the inventory it ends on. |
| [[item:extract_lens]] | Takes items from the inventory it ends on. |
| [[item:redstone_lens]] | Gives the block it ends on a redstone signal. |

Click an action for what it does, what it costs and which modifiers change it. For every action and modifier at once, see the matrix below.
