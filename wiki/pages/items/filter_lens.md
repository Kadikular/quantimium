[[mechanic:laser.lens.filter]] Item Filter Lens limits the item actions before it to the items it lets through.

## How it works

- Insert, Extract, Pickup and Placement read it.
- Nine entries, set as allow or deny, with tags (shift-click an entry).

## Settings

Use the lens in the air to set it.

## Energy

Free.

## Applies to

The three filter lenses split the work: this one for items, [[item:block_filter_lens]] for Harvest, [[item:entity_filter_lens]] for hits and interactions.

| Action | Filter that applies |
| --- | --- |
| [[item:place_lens]] | Item Filter Lens: places only the listed items. |
| [[item:insert_lens]] | Item Filter Lens: moves only the listed items. |
| [[item:extract_lens]] | Item Filter Lens: takes only the listed items. |
| [[item:pickup_lens]] | Item Filter Lens: carries only the listed items. |
