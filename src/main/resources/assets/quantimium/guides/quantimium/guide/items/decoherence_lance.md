# Decoherence Lance

<ItemImage id="quantimium:decoherence_lance" scale="2" />

> *In game:* Hold to channel. Closes rifts; harms only what is caught between worlds.

The one tool that reaches into the rift. Held from the [mirror](../mirror/mirror-phase.md), its beam
[closes flux rifts](../mirror/flux-rifts.md), unmakes mirror mites, and
[wears down the Veiled](../mirror/veiled.md).

It runs on FE, holding 200,000: charge it in any mod's item charger, or keep it
topped up from an <ItemLink id="quantimium:entangled_dock" />.
