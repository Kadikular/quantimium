# Horizon Core

<ItemImage id="quantimium:horizon_core" scale="2" />

Part of the [Quantimium Reactor](../multiblocks/reactor.md).

Fixed 11-wide plinth disc; a Singularity seated in the Horizon Core holds an exact ledger (1M items, x4 per ring pair, up to 3); up to 8 Catalyst Bays. One list of everything held or makeable, counted loop-safe off-thread; taking plans the whole tree through every catalyst, all or nothing. Output ports for the screen, a Materialiser Port for pipes and storage buses. No dangers yet.
