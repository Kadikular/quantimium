# ME Superposition Port

<ItemImage id="quantimium:reactor_me_port" scale="2" />

Part of the [Quantimium Reactor](../multiblocks/reactor.md).

The ME Superposition Port joins the [Reactor](../multiblocks/reactor.md) to an AE2 network both ways. It goes on the plinth rim and takes a channel. It needs AE2.

- **Storage:** what the Reactor holds shows in the network's terminal and can be taken like anything in a drive. With **Storing** on, the network can also store items in the Reactor, at the port's priority.
- **Patterns:** what the Reactor can make is offered as patterns, so AE2 plans from everything on the network. Mode: **Both** (default), **Whole trees** (one pattern per thing, fast) or **Steps** (one per recipe).
- **Filter:** two lists, one for patterns and one for storage, each allow or deny.
- What the network holds, the Reactor counts and uses as its own inputs.

See [the Reactor page](../multiblocks/reactor.md) for the details.
