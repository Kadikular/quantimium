# Isolators

An <ItemLink id="quantimium:isolator" /> passes a laser on as a relay does, but lets only power through. The laser leaving it carries nothing it did (actions, Pickup, UV), and nothing comes back up through it, so Pickup's items stop short of it.

- It is a plain block. Sneak-click or wrench a face to add an output there or take one away (one always stays).
- Use an empty hand to step through how it listens to redstone.

## Isolator Lens

An <ItemLink id="quantimium:isolator_lens" /> does the same in a Lens Mount or a Focus Emitter, and can be set to let more through. See its page for the settings. An Isolator alone in a crafting grid makes one. An Isolator Lens also stops Pickup's items, unless it is set to pass a logistics network.
