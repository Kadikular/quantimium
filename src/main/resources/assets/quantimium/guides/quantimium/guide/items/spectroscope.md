# Spectroscope

<ItemImage id="quantimium:spectroscope" scale="2" />

The Spectroscope reads a laser. Use it on any laser block to see what the laser leaving it carries.

- How far a run reaches, and from how many sources.
- Each action with its modifiers, who pays, and how many Laser Ports it can reach.
- Each laser's length, end and power.

See [Networks and rules](../lasers/networks.md).
