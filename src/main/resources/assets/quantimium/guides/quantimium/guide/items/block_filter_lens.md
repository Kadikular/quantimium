# Block Filter Lens

<ItemImage id="quantimium:block_filter_lens" scale="2" />

A lens: a Harvest beam cuts only the blocks it lets through, and with ripe only, only what's fully grown. Put it alone in a crafting grid to make it an Entity Filter Lens.
