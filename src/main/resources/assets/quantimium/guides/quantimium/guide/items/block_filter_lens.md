# Block Filter Lens

<ItemImage id="quantimium:block_filter_lens" scale="2" />

Block Filter Lens limits a Harvest laser to the blocks it lets through.

## How it works

- Matches by the block or anything it drops, so "wheat" lets only ripe wheat be cut.
- Nine entries, set as allow or deny.
- **Ripe only**: only crops (and anything else that grows) that are fully grown. It never cuts what doesn't grow, so never the farmland.

## Settings

Use the lens in the air to set it.

## Energy

Free.

## Examples

- **Wheat farm.** Ripe only. See [Examples](../lasers/lenses/examples.md).
- **Ore miner.** Set to ores, with Phantom: only the ore in the ground is cut.
