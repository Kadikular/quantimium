# Pod Recovery Module

<ItemImage id="quantimium:pod_recovery_module" scale="2" />

Part of the [Superposition Pod](../multiblocks/superposition-pod.md).

A <ItemLink id="quantimium:superposition_pod" /> module, set in one of the four edges of its <ItemLink id="quantimium:pod_cradle" />. It works while the pod holds one of your doubles.

Brings a lost double home to its pod, from anywhere: a field double still standing is folded up where it stands, and a Sophon lying where a double was knocked out is lifted from the ground. Manually (open the pod, pick the double, **Recover**) or by itself when one is knocked out.

Draw: what it brings.

See the [Superposition Pod](../multiblocks/superposition-pod.md) page.
