# Laser Isolator

<ItemImage id="quantimium:isolator" scale="2" />

The Isolator passes a laser on as a relay does, but lets only power through. The laser leaving it carries nothing it did (actions, Pickup, UV), and nothing comes back up through it.

- Sneak-click or wrench a face to add an output there or take one away. One always stays.
- Use an empty hand to step through how it listens to redstone.
- The <ItemLink id="quantimium:isolator_lens" /> does the same in a Lens Mount, and can be set to let more through.

See [Isolators](../lasers/isolator.md).
