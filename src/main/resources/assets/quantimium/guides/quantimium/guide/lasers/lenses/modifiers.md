# Modifier lenses

A modifier changes the actions a laser already carries when it meets it: those in slots to its left in the mount, and those from mounts before. It never changes one that comes after.

## Reach

| Lens | What it does |
| --- | --- |
| <ItemLink id="quantimium:range_lens" /> | Doubles how far each run reaches. |
| <ItemLink id="quantimium:phantom_lens" /> | The laser passes through blocks. Costs power per block, and doubles action costs. |

## Targeting

| Lens | What it does |
| --- | --- |
| <ItemLink id="quantimium:filter_lens" /> | Limits item actions to listed items. |
| <ItemLink id="quantimium:block_filter_lens" /> | Limits Harvest to listed blocks. |
| <ItemLink id="quantimium:entity_filter_lens" /> | Limits Damage, Healing, Freezing and Interact to listed entities. |

## Output

| Lens | What it does |
| --- | --- |
| <ItemLink id="quantimium:pickup_lens" /> | Returns freed items up the laser to a Laser Port. |
| <ItemLink id="quantimium:void_lens" /> | Destroys freed items nothing takes. |
| <ItemLink id="quantimium:smelting_lens" /> | Smelts items on the way. |
| <ItemLink id="quantimium:crushing_lens" /> | Crushes items on the way. |
| <ItemLink id="quantimium:unrealising_lens" /> | Ore comes away as Unrealized Matter. |

## Power and speed

| Lens | What it does |
| --- | --- |
| <ItemLink id="quantimium:amplify_lens" /> | Harder cuts, harder hits and heals. |
| <ItemLink id="quantimium:speed_lens" /> | Actions work twice as fast per lens. |

## Harvest quality

| Lens | What it does |
| --- | --- |
| <ItemLink id="quantimium:precision_lens" /> | Silk Touch. |
| <ItemLink id="quantimium:harmonic_lens" /> | Fortune and Looting. |

## Control

| Lens | What it does |
| --- | --- |
| <ItemLink id="quantimium:isolator_lens" /> | Lets power through, and only what else it is set to pass. |
| <ItemLink id="quantimium:uv_lens" /> | Hides the laser. |
