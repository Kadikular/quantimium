# Logistics Terminal

<ItemImage id="quantimium:logistics_terminal" scale="2" />

The Logistics Terminal shows everything a logistics network's storage holds and its providers offer, like an ME terminal. Place it where a controller's laser ends.

- Searchable, sorted by count or name. Click for a stack, right-click for half, shift-click into your inventory.
- Stored items come out first. Only when none is left does a machine make more.
- A crafting grid tab works like an ME crafting terminal, with JEI support.
- Each take or put costs the controller as a move does.

See [Logistics](../lasers/logistics.md).
