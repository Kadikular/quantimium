# Focus Stand

<ItemImage id="quantimium:focus_stand" scale="2" />

The Focus Stand is a base for a Laser Focus. It stands the focus on the block behind it. Add as many as you like. No laser gets in or out by it.

See [Laser Focus](../lasers/focus.md).
